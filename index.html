Low-cost mini JCB-style
robotic excavator arm

A compact excavator-arm study exploring how linked members and simple actuation can reproduce a useful digging motion at an accessible scale.

Design objective

Develop a low-cost arm concept with a stable base, clear joint motion, and a bucket path suitable for a small demonstration prototype.

Mechanism & actuation

Document the boom, dipper, bucket linkage, pivot locations, and actuator choice here. Add the actual actuator type, stroke, mounting points, and motion limits after confirming the build.

Materials & fabrication

Add the materials, stock thicknesses, fasteners, and manufacturing methods used (for example: cutting, drilling, printing, or hand fabrication). No material or process is assumed yet.

Challenges & next iteration

Record observed joint play, structural deflection, stability, and bucket control. Note the change made for each issue and what should be tested next.

02 / SMART MONITORINGARDUINO · SENSING · ALERT

Smart underground water
leakage detection system

A proposed sensing system to identify water leakage along an underground route and alert a user, linking a sensor arrangement to an Arduino-based controller.

Problem & approach

Underground leaks can be difficult to spot early. The concept places sensing points near a pipe route and uses a controller to interpret a detection signal and trigger an alert.

Sensor arrangement

Add the actual sensor model, placement interval, wiring layout, and test conditions. The drawing is a system block diagram, not a finished circuit schematic.

Components

Arduino board (exact model to add), leak sensor(s) (type to confirm), alert device (LED / buzzer / other), power source, and connecting wires. Update this list to match the prototype.

Working principle

The sensor provides an input to the controller; the program checks that input against the chosen detection condition and activates the configured alert. Add threshold, timing, and reset behavior from the actual implementation.
